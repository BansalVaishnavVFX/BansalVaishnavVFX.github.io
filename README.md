# Bansal — VFX Portfolio Coming Soon

## Publish with GitHub Pages

1. Download and extract this folder.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the **root** of your `username.github.io` repository.
3. Commit the files to the repository's publishing branch (usually `main`).
4. In GitHub, open **Settings → Pages** and confirm the source is set to deploy from the `main` branch and `/ (root)`.
5. Open `https://username.github.io` (replace `username` with your GitHub username).

The page is responsive and uses no build tools. Google Fonts are loaded online; the page still works with fallback fonts if they are unavailable.
